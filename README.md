# py-agent-learn

Python Agent 学习路径，按阶段逐步深入。

## 目录结构

```
py-agent-learn/
├── phase01-basic/        # 基础：Python
│   └── python/
├── phase02-framework/    # 框架：Mini-Agent、LangChain、LangGraph、FastAPI
│   ├── mini-agent/
│   ├── langchain/
│   ├── langgraph/
│   └── fastapi/
├── phase03-core/         # 核心：RAG、MCP
│   ├── rag/
│   └── mcp/
├── phase04-advanced/     # 进阶：多 Agent、评测
│   ├── multi-agent/
│   └── evaluation/
└── projects/             # 项目实战
```

## 快速开始

```bash
# 安装依赖
pip install -e .

# 复制环境变量示例
cp .env.example .env
```
